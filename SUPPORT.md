# Support

Use [Pannonico Issues](https://github.com/vx-rs/pannonico/issues) for CLI usage
questions, compatibility reports, and reproducible bugs. Search existing issues
before opening a new one.

Include the Pannonico version, installation method, Node/npm versions when
applicable, operating system and architecture, the exact command, a minimal
project, expected behavior, actual behavior, and redacted terminal output.
Remove credentials, personal data, private paths, and confidential project
content.

Use the private process in [SECURITY.md](SECURITY.md) for suspected
vulnerabilities.
