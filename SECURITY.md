# Security policy

## Supported versions

Security fixes are provided for the latest released Pannonico version. This
policy covers the CLI npm packages, standalone release assets, and Visual
Studio Code extension.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| Earlier versions | No |

## Report a vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/vx-rs/pannonico/security/advisories/new).
Do not disclose the issue publicly before it has been investigated.

Include the affected version, environment, reproduction steps, impact, and any
suggested mitigation. Remove credentials, personal data, and confidential
project content from the report and attachments.
