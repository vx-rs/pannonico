# Security policy

Report suspected vulnerabilities for the Pannonico CLI, language server, or VS
Code extension through the shared
[GitHub private vulnerability reporting form](https://github.com/vx-rs/pannonico/security/advisories/new).
Do not disclose vulnerability details in any public issue tracker.

Include the affected component and version, environment, reproduction steps,
impact, and any suggested mitigation. Remove credentials, personal data, and
confidential project content from reports and attachments.

Security fixes are coordinated privately and released before public disclosure.
